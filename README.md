# Student Management System (Django)

A web-based Student Management System developed using Django.  
This project provides an organized way to manage students, teachers, courses, and subjects with role-based access control and a clean, responsive user interface.

## 🚀 Features
- User authentication (Login / Register / Logout)
- Role-based access (Admin / Staff / Users)
- Student management (Create, update, list, soft delete)
- Teacher management with subject assignment
- Course and subject management
- CSV import & export for student data
- Activity logging and audit trails
- Responsive UI using Bootstrap
- Centralized base layout with reusable header and footer

## 🛠️ Tech Stack
- **Backend:** Django (Python)
- **Frontend:** HTML, CSS, Bootstrap 5
- **Database:** SQLite (can be switched to PostgreSQL/MySQL)
- **Authentication:** Django built-in auth system

## 📂 Project Structure
- Modular Django apps
- Reusable base template for consistent UI
- Static files and templates organized by feature
- Class-based views for clean and maintainable code
